🏆 MakerWorld Contest Theme Study

Theme & Category Demand Analysis · 158 design contests · Oct 2023 – Sep 2026
📓 Python Notebook 🗂️ Dataset (CSV) 🌐 Data source

🎯 Business Question

MakerWorld runs a new 3D design contest almost every week. Which themes attract the most makers and the most attention, and which contests were the best and worst performers? This study scores every finished contest, groups them into six theme categories and turns the patterns into recommendations for planning the next contest calendar.

    🔬 Methodology

    • Data collection: public MakerWorld contests page (all 158 contest cards) plus each contest's detail page (prize list and winners), collected on 25 Sep 2026 with a small JavaScript script in the browser.
    • Metrics: models submitted, participants and views as shown on each contest card. Participants are counted per contest, so one maker who joins several contests is counted several times.
    • Scope: finished contests are scored. The 8 contests still running on the snapshot date are shown in the dataset but not ranked.
    • Composite score: percentile rank of participants (40%), models per day (30%) and views (30%). Tiers: S = top 10%, A = next 20%, B = middle 40%, C = bottom 30%.
    • Categories: assigned by hand from each contest's theme brief (6 categories). Brand-sponsored contests are flagged separately.
    • Holiday mega-contests: Halloween, Christmas/Printmas, Valentine's and Easter editions ( contests).

    Limitations: views keep growing after a contest ends, so older contests have a small advantage (Spearman correlation between views and contest age = ). Prize values count only USD gift cards and cash, not printers or points. Categories involve judgment and can be reclassified in the notebook.
